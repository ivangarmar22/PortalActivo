## Qué se ha incorporado a PortalActivo

| Función                                           | Inspiración                                | Cómo se ha hecho                                                                                                                  |
| ------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Incidencias en tiempo real con foto y responsable | ResidenciAPP, PropApp, LiVe Fincas         | Estado, responsable (administración, promotora, empresa, seguro), previsión e historial; los vecinos ven cada cambio sin recargar |
| Reservas con control de disponibilidad            | ResidenciAPP, BuildingLink                 | Franjas fijas, confirmación inmediata y la base de datos impide las dobles reservas                                               |
| Avisos + tablón vecinal                           | Fincapp, Colindar, Condo Control           | Avisos con urgencia, fijado, adjunto, caducidad y lectura; tablón con aprobación previa                                           |
| Recibos y documentos                              | TucomunidApp, Fynkus                       | Recibos privados por vivienda y documentos económicos visibles para todos                                                         |
| Acceso limitado para votar                        | TucomunidApp (perfiles con acceso parcial) | Acceso de «solo votación» con PIN, separado del acceso completo                                                                   |

## Propuestas para siguientes versiones

En orden de valor estimado:

1. **Notificaciones push o por email** cuando cambia una incidencia, se publica un aviso urgente o se abre una votación. Es la función más citada.
2. **Delegación de voto y voto ponderado por coeficiente**, necesarios para que una votación tenga encaje legal.
3. **Perfil de inquilino**, con incidencias, reservas y avisos, pero sin recibos ni votaciones.
4. **Encuestas rápidas** de una sola pregunta fuera de las juntas.
5. **Calendario de la comunidad** con juntas, obras, limpiezas y reservas en una sola vista.
6. **Pago online de recibos**, con pasarela y conciliación bancaria.
7. **Mensajería con la administración** (chat o tickets privados) para lo que no es una incidencia común.
